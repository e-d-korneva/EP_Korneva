# Веб-приложение «Агрегатор рецептов»

## Описание
Платформа для поиска, фильтрации и систематизации кулинарных рецептов. 
Включает интеграцию с API TheMealDB, личный кабинет, систему коллекций и админ-панель.

## Стек технологий
*   Backend: PHP 8.2 (PDO)
*   Frontend: HTML5, CSS3, JavaScript
*   Database: MySQL
*   Server: Apache (XAMPP)

## Инструкция по запуску
1. Скопируйте файлы проекта в корневую директорию сервера (например, `htdocs` в XAMPP).
2. Откройте phpMyAdmin и создайте базу данных с именем `recipe` (кодировка `utf8mb4_general_ci`).
3. Импортируйте дамп базы данных из файла `recipe.sql`.
4. Проверьте настройки подключения в файле `config.php` (по умолчанию: `root`, без пароля, `localhost`).
5. Откройте сайт в браузере по локальному адресу.
